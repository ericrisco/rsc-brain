   Watch it complete:
     kubectl -n {{ .Release.Namespace }} get jobs -l app.kubernetes.io/component=migrate -w

2. Open the console + MCP at:
{{- if .Values.ingress.enabled }}
     https://{{ .Values.ingress.domain }}/        (admin console)

{{- if not .Values.ingress.clusterIssuer }}

   NOTE: ingress.clusterIssuer is unset, so NO TLS was provisioned. OAuth to Claude/ChatGPT
   requires HTTPS (D11) — set ingress.clusterIssuer to a working cert-manager ClusterIssuer.
{{- end }}
{{- else }}
     (ingress disabled — port-forward the api/console Services to reach them)
{{- end }}

3. First-admin login. Email: {{ .Values.admin.email }}
   The password was auto-generated (unless you set admin.password). Retrieve it from the Secret
   (it is never printed in these notes or in migration logs):
     kubectl -n {{ .Release.Namespace }} get secret {{ include "rsc-brain.secretName" . }} \
       -o jsonpath='{.data.RSC_BRAIN_ADMIN_PASSWORD}' | base64 -d ; echo
4. Verify the running system (same check as the api readiness probe):
     kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "rsc-brain.fullname" . }}-api -- brain verify

Secrets (DB password, admin password) are auto-generated and PRESERVED across `helm upgrade`.
Helm render output can contain Secret manifests, so keep rendered output in a private location and
delete it after review.
Configure all five model capabilities and a reachable provider before ingestion or recall. The
readiness command above checks configuration and database state without contacting the provider.

console.extraEnv before upgrade.
